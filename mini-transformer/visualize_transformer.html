🏗️ Arquitectura del Transformer Decoder-Only

Esta es la arquitectura que usa nuestro mini modelo. Es un decoder-only Transformer, similar a GPT. Cada bloque procesa la secuencia completa y pasa su resultado al siguiente.

💡 ¿Por qué "Decoder-Only"? El Transformer original (2017) tenía encoder + decoder. Para generación de texto puro (como GPT), solo necesitamos el decoder con su máscara causal: cada token solo puede "ver" los tokens anteriores, no los futuros. Esto permite generar texto token por token de izquierda a derecha.

👁️ Visualización de Attention Weights

Este mapa de calor muestra cuánta "atención" presta cada token a los demás. Colores más brillantes = mayor atención. La máscara causal (triangular inferior) impide que los tokens vean al futuro.

📖 Cómo leer el mapa: El eje Y representa el token "que pregunta" (Query) y el eje X el token "al que atiende" (Key). Un color brillante en la posición (i, j) significa que el token i presta mucha atención al token j. La zona negra superior-derecha es la máscara causal.
