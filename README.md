# AI playground repo

This repo contains different AI projects testing AI capabilities.

## Projects

- `chatter-agent` – generates messages about random subjects.
- `chat-agent` – knowledge agent with memory using LangChain.
- `websites-chatbot` – chatbot that answers questions about scraped websites.
- `multi-agent-chat` – simple REST chatbot with 15‑minute memory and Docker setup.
- `mini-transformer` – A transformer implementation depicting how a generator works.
